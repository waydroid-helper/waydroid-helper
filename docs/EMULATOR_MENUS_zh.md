# MuMu 标题栏与 Waydroid 嵌入窗口

参考环境为 Windows 上的 MuMu 5.30.1.3586、Android 12，以及 GNOME Wayland 上的 Waydroid Helper。以下菜单名称来自实际展开的 MuMu 标题栏。Waydroid 的显示测试使用嵌入窗口自己的 Android 实例。

## 窗口、全屏与 Android 分辨率

MuMu 在「更多 → 设备设置 → 显示 → 分辨率设置」中选择 Android 输出。自定义可以分别设置宽、高和 DPI。应用更改需要重启模拟器。窗口管理中的 F11 只改变宿主显示区域。拖动窗口边角也能缩放画面。

两边都选手机预设。每一步通过 ADB 读取 Android 的有效尺寸和密度。MuMu 的画面区域取自 Windows 渲染子窗口，Waydroid 的画面区域取自 GTK 内容坐标，并按桌面缩放换算为物理像素。显示器为 3200 × 2000。

| 操作 | MuMu 画面（物理像素） | Waydroid 画面（物理像素） | 两边的 Android 显示 |
| --- | --- | --- | --- |
| 窗口模式 | 984 × 1748 | 1012 × 1800 | 1080 × 1920，480 DPI |
| 进入全屏 | 1124 × 2000 | 1124 × 2000 | 1080 × 1920，480 DPI |
| 退出全屏 | 984 × 1748 | 1012 × 1800 | 1080 × 1920，480 DPI |

两边的窗口初始大小各自独立。全屏时竖屏画面居中，左右留黑。Waydroid 在未设预设的横屏会话也做了测试，窗口与全屏均为 1920 × 1080、360 DPI。此处的 360 是该实例的原始密度，与下表中 MuMu 指定的平板预设独立。

| 类型 | 分辨率与 DPI |
| --- | --- |
| 平板 | 3840 × 2160 / 540，2560 × 1440 / 360，1920 × 1080 / 280，1600 × 900 / 240 |
| 手机 | 2160 × 3840 / 960，1440 × 2560 / 640，1080 × 1920 / 480，900 × 1600 / 320 |
| 超宽屏 | 3440 × 1440 / 480，2560 × 1080 / 360，1920 × 864 / 240，1680 × 720 / 240 |
| 自定义 | 宽度、高度、DPI |

Waydroid Helper 的「更多 → 设备设置 → 显示」提供以上预设和自定义设置。用户选择预设后，重启 Android 应用新的输出模式。未选择预设时，嵌入窗口沿用 Waydroid 已配置的输出，或在首次分配画面区域时确定输出尺寸。随后缩放窗口和切换全屏都使用 GTK 变换，同时缩放 Android 画面和键位映射层。

## 标题栏菜单对照

| MuMu 入口 | 展开的项目或操作 | Waydroid Helper 当前实现 |
| --- | --- | --- |
| 安卓导航键 | 返回、多任务、首页 | 三个 Android 导航动作 |
| 窗口管理 | 全屏 F11、窗口置顶、迷你模式 Alt+G、屏幕旋转、恢复窗口默认大小 | 全屏、迷你、手动旋转、恢复大小。置顶使用桌面环境的系统窗口菜单 |
| 键鼠 / 手柄 | 键鼠和手柄方案、新建方案、编辑器内的重命名、清空、取消和保存 | 已有 JSON 键位布局、控件编辑和保存。手柄按键可通过 libmanette 绑定，实体手柄体验尚待验证 |
| 操作录制 | 独立方案窗口、搜索、新建录制、导入 | 录制与回放输入，导入与导出单个 JSON 方案 |
| 虚拟定位 | 地图和位置搜索 | 输入经纬度、设置与清除模拟位置 |
| 更多工具 | 截图 F9、录屏、安装 APK、音量 Ctrl+0、摇一摇、共享文件夹 | 截图、录屏、APK、媒体音量和共享目录入口。当前测试镜像的 Android SensorService 报告零个传感器，摇一摇仍待实现 |
| 更多工具 → 共享文件夹 | 打开电脑端、打开安卓端、更改共享文件夹路径 | 复用 Helper 共享目录配置和对应的宿主、Android 目录入口 |
| 设备设置 | 显示、窗口位置与大小、帧率、画面，以及性能、声音、磁盘、网络、机型、快捷键、开发者等页 | 分辨率、DPI、固定窗口大小、记住窗口大小。随应用自动旋转窗口、帧率和画面设置等尚未移植 |
| 帮助中心 | 常见问题、问题诊断、意见反馈 | 使用指南、当前设备诊断、项目问题反馈 |
| 重启设备 | 重开 Android 会话 | 在嵌入窗口确认并重启 |
| 动态栏 | 点击后菜单收起，本次没有观察到可识别的面板内容 | 行为待确认 |
